# Ashutosh Kumar Yadav - Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

🌐 **Live at:** [ashutoshky.vercel.app](https://ashutoshky.vercel.app)

## 🚀 Features

- **Modern Dark Theme** with B&W glassmorphism effects and light mode toggle
- **Smooth Scroll Animations** triggered on viewport entry (Intersection Observer)
- **Responsive Design** works on all devices (mobile-first breakpoints)
- **Mobile Navigation** with animated hamburger menu
- **Background Particles** — subtle floating particle animations
- **Avatar Cycling** — animated profile image frames
- **Performance Optimized** — throttled scroll handlers, no frameworks
- **SEO Ready** — Google Analytics, structured data, Open Graph, sitemap

## 📁 Project Structure


- **HTML5** — Semantic markup with structured data (JSON-LD)
- **CSS3** — Custom properties, CSS Grid, Flexbox, animations, media queries
- **JavaScript** — Vanilla JS, Intersection Observer, Web Audio API, throttle/debounce

## 🚀 Getting Started

1. Clone this repository
2. Open `public/index.html` in your browser
3. That's it! No build step required.
