# Ashutosh Kumar Yadav - Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features

- **Modern Dark Theme** with glassmorphism effects
- **Smooth Scroll Animations** triggered on viewport entry
- **Responsive Design** works on all devices
- **Mobile-First Navigation** with hamburger menu
- **Performance Optimized** with throttled scroll handlers
- **Lightweight** - No frameworks, pure HTML/CSS/JS

## 📁 Project Structure

```
my-site/
├── index.html          # Main HTML file
├── css/
│   ├── style.css       # Main styles
│   ├── variables.css   # Design tokens (colors, fonts, spacing)
│   └── animations.css  # Animation keyframes
├── js/
│   └── main.js         # Interactions and scroll effects
├── assets/
│   └── images/         # Profile photo, project screenshots
└── README.md           # This file
```

## 🎨 Sections

1. **Hero** - Introduction with animated elements
2. **About** - Bio and quick stats
3. **Skills** - Technical skillset organized by category
4. **Experience** - Professional timeline
5. **Projects** - Portfolio of work
6. **Education** - Academic background
7. **Achievements** - Highlights and recognition
8. **Contact** - Contact form and social links

## 🛠️ Getting Started

1. Clone or download this repository
2. Open `index.html` in your browser
3. That's it! No build step required.

## 📱 Responsive Breakpoints

- Mobile: < 480px
- Tablet: < 768px
- Desktop: < 968px
- Large: > 968px

## 🚀 Deployment

Deploy to any static hosting:
- **GitHub Pages**: Push to `gh-pages` branch
- **Netlify**: Drag and drop or connect GitHub
- **Vercel**: Import from GitHub
